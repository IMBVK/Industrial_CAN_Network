# Industrial CAN Network & Diagnostics Platform

A multi-node embedded CAN communication and diagnostics platform developed using microcontrollers, MCP2515 CAN controllers, TJA1050 CAN transceivers, and Vector CANoe/CANalyzer tooling.

## Project Status

Day 1 – CAN fundamentals and system architecture

## Planned Features

- Classical CAN 2.0B
- Multi-node communication
- CAN arbitration
- CAN message filtering
- Interrupt-driven reception
- Real-time message scheduling
- Heartbeat monitoring
- Diagnostics
- Fault handling
- CANopen concepts
- CAN FD study
- CANoe/CANalyzer analysis
- CAPL
- Automated testing
- Python-based test automation
